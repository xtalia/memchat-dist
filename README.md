# Хатико · Memchat для Chrome

Chrome Manifest V3, версия этой исходной сборки **2026-11-27 · beta**, технический номер **8.9.0.23**, Chrome 141+. Доступные выпуски указаны в разделе «Скачать». Tampermonkey и Node/Python для установки не нужны.

## Основной UI в sidebar

Нажми значок расширения или ПКМ → **Открыть боковую панель Memchat**. Повторный клик по значку закрывает панель. Основное окно, ввод, результаты, выбор товара и настройки находятся внутри штатной панели Chrome, а не поверх сайта. В верхней строке — версия и работающие статусы Bearer/Panel. Крестик также закрывает панель. История чата и введённый текст принадлежат открытому документу панели: после закрытия или перезагрузки панели они начинаются заново, а настройки, Bearer и выбранная вкладка сохраняются.

Изменения элементов страницы, очистка полей и quick tools остаются на поддерживаемых страницах. Панель открывается на любой вкладке, включая `chrome://`, и работает без открытой рабочей страницы. На рабочем сайте использует его данные; на сторонней вкладке — данные последнего использованного рабочего сайта, иначе МойСклада. Данные сайтов не смешиваются. Незавершённые записи не объявляются сохранёнными; при ошибке используй ↻.

На поддерживаемой вкладке сохраняется существующий content runtime; на сторонней вкладке создаётся приватный extension runtime, привязанный к выбранному origin, без iframe сайта и внедрения в стороннюю страницу. Sidebar отображает ограниченное inert-представление и передаёт узкие команды. Отдельные origin-хранилища сохраняются; черновик и история автономной панели живут в её документе и не пишутся в хранилище. Clipboard работает через clipboardWrite.

**Updater V3 (из 8.9.0.11) менять не нужно:** сохранены ровно девять runtime-файлов. Старые V1/V2 readers по-прежнему требуют прежнего разового перехода на V3. Техническая numeric version сохраняет монотонную нумерацию; видимая версия — дата + тип. release.json допускает alpha/beta/RC/release.

## Предыдущий опубликованный этап (8.9.0.11)

- Оповещатель показывает одно системное уведомление и воспроизводит один общий сигнал из расширения, без тостов и звука в каждой вкладке МойСклад.
- При включённой функции значок кнопки расширения становится мишкой; при выключении возвращается обычный. Новая вкладка не запускает повторный immediate poll.
- Прежний MP3 включён в пакет: воспроизведение через один скрытый offscreen-документ не зависит от страниц и сторонней загрузки аудио. Браузер должен оставаться открытым.
- Добавлены разрешения notifications/offscreen и формат обновлятора V3 с девятью файлами. Расчёты, private storage, Panel recovery и прямой MS transport сохранены.

## Обновить существующую установку

1. Для установки **8.9.0.11/V3** запусти прежний обновлятор без замены файлов:
   - Windows: `Update-Memchat.cmd` и соседний `Update-Memchat.ps1`.
   - macOS: `Update-Memchat.command` и соседний `update-memchat.sh`.
   - Linux: `bash /путь/к/update-memchat.sh`.
2. Дождись успешного результата.
3. На `chrome://extensions` нажми круглую стрелку **Перезагрузить** на карточке Memchat; проверь версию полученного релиза в панели.
4. Перезагрузи рабочие вкладки МойСклад, Bitrix24 и Hatiko, включая Panel при её использовании.

**Не удаляй расширение, не меняй путь и не устанавливай вторую копию:** это важно для сохранения extension ID и private settings/history. Папочный backup обновлятора содержит код, не данные Chrome.

При переходе на V3 обязательно один раз замени четыре соседних launcher-файла из нового ZIP. Даже updater версии 8.9.0.10 принимает только V1/V2 и безопасно отвергнет V3. Затем обновляй прежнюю chrome-extension; переустановка не нужна. Обновлятор не обновляет сам себя.

При другом пути установки:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./Update-Memchat.ps1 -TargetDirectory "D:/Tools/MyMemchat"
```

```sh
bash ./update-memchat.sh --target "/путь/к/установленной/папке"
```

## Установить впервые на другом ПК

1. Распакуй ZIP в постоянную папку, например `D:/Tools/Memchat` или `~/Applications/Memchat`.
2. Отключи Memchat production/DEV в Tampermonkey, если они установлены.
3. Открой `chrome://extensions` → включи **Режим разработчика** → **Загрузить распакованное расширение**.
4. Выбери внутреннюю папку **chrome-extension**, где лежит manifest.json, не ZIP и не родительскую папку.
5. Перезагрузи рабочие сайты. При необходимости настрой Bearer на этом ПК и войди в Panel в том же профиле Chrome.

Настройки/авторизация автоматически между ПК не синхронизируются. Не пересылай ключи в чат; они не входят в ZIP.

## Быстрая проверка после обновления

- Значок открывает настоящий sidebar; основное окно больше не показывается поверх сайта. Закрытие/reopen панели начинает историю и поле заново; выбранная вкладка и настройки сохраняются.
- Скидка `142490-3156` показывает `2.214892273141975%` и итог `139334 руб.`.
- Быстрый переключатель очистки работает до открытия настроек; Enter очищает поле только во включённом режиме.
- «Сегодня/Завтра» загружаются, «Правила и замены» сохраняются после перезагрузки страницы.
- Проверяются bearer/panel и нужные уведомления; при входе в Panel используй тот же профиль Chrome.

Если проблема: пришли версию, сайт/вкладку, действие и текст ошибки/скриншот. Токены, телефоны и cookies в отчёт не включай.

## Поведение и безопасность

- Настройки и Bearer — в private chrome.storage.local с TRUSTED_CONTEXTS; origins/аккаунты разделены. История чата хранится только в документе боковой панели и в хранилище не попадает, поэтому телефоны бонусов и текст запросов в private storage не оседают. Ранее сохранённая история не удаляется, но в новый чат не читается.
- Panel использует браузерную cookie-сессию. CSRF не восстанавливает истёкший вход. Сначала фоновая проверка; при необходимости — bounded recovery через уже открытую подходящую Panel-вкладку. Cookies/CSRF не копируются в постоянное хранилище; новые вкладки автоматически не открываются. Красный Panel-индикатор открывает сайт только по явному клику.
- MS-запросы extension идут без локальной очереди/caps/pacing/quota. Временно неуспешное чтение повторяется один раз; неоднозначные записи не переигрываются вслепую. Ключ проверяется на актуальность.
- Заказы опрашивает один worker alarm на профиль. Native notification/звук работают без открытых поддерживаемых вкладок, пока браузер открыт и есть session-конфигурация опроса. После полного перезапуска браузера Bearer/config снова задаётся через поддерживаемую страницу. Сон ОС задерживает alarms; баннер зависит от разрешений Chrome/ОС и режима «Не беспокоить». Системный beep выключен, чтобы не дублировать собственный сигнал. Звук можно выключить прежним checkbox. Длительность ограничивает хранение уведомления; ОС может раньше свернуть его баннер. Ноль — без нашего таймера удаления.
- Основной UI находится в native sidebar. Quick tools/предупреждения страницы сохраняют top layer; ПКМ → сброс положения окон относится к оставшимся page-окнам.
- Все executable scripts локальны. Изоляция модулей — не песочница от вредоносного кода; поля UI остаются DOM, а данные профиля доступны владельцу компьютера.
- Дополнительные удалённые замены расписания могут возвращать private GitHub 404; встроенный fallback сохранён.

## Recovery при конфликте и заполнении

Все отклонённые варианты остаются приватными; список показывает только ID/ключ/версию, не содержимое или токены. Лимиты — 128 вариантов и 5 Mi символов JSON на origin (не UTF-8 MiB), плюс quota Chrome. Автоматического удаления нет.

При заполнении Restore честно откажет: ему нужно место для вытесняемого текущего значения. Выбери **заведомо ненужный** вариант → «Удалить выбранный вариант навсегда» → проверь ID в отдельном подтверждении. Отмена ничего не меняет; подтверждение необратимо удаляет **только выбранный вариант**, без экспорта секретов. Текущее значение и остальные варианты сохраняются. Затем повтори сохранение/Restore; для большого вытесняемого значения может потребоваться освободить больше одного варианта. Если варианты нужны все, не подтверждай удаление: оставь вкладку открытой; автоматического архива нет.

Удаление/Restore сериализуются worker, пишут один origin bucket и подтверждаются только после read-back. IDs не переиспользуются; document fence сохраняется после удаления. Пока есть неподтверждённый запрос, warning виден **до первого ack**, Reload/Restore скрыты. После отказа очистка доступна и при сохранённом pending intent; Retry повторяет исходный payload. Закрытие/потеря питания **до durable ack** не гарантируют сохранность; warning не блокирует системное закрытие.

## Обновлятор

Получает fixed publisher descriptor и versioned GitHub Release ZIP, проверяет SHA-256 архива/всех runtime-файлов объявленной schema, готовит staging и сохраняет предыдущую папку. При ошибке проверки старая установка не меняется; при ошибке замены выполняется восстановление. Не допускаются посторонняя папка, downgrade, небезопасный архив и параллельная замена того же target. Same-version no-op проверяет целостность; повреждение той же версии восстанавливается.

V3 runtime: manifest.json, build-info.json, config.js, content.js, worker.js, controls.js, icon.png, offscreen.html, audio-player.js. Sidebar — исходные модули, не дополнительные runtime entries. Readers понимают точные V1/V2/V3 наборы (новые source readers дополнительно сохраняют строгую V4-ветку; текущий пакет её не использует). Launchers и README находятся рядом. Windows требует PowerShell 5.1/7; Bash-ветка — curl, unzip и shasum/sha256sum. Python/jq/Node не нужны. Не отключай Gatekeeper и не меняй глобальную PowerShell policy; при потере executable bit у доверенного .command можно выполнить chmod +x.

Hash — проверка целостности, не независимая подпись издателя. Профиль Chrome и его cookies updater не редактирует. Reload расширения и рабочих страниц остаётся ручным действием.

## Для разработки

Авторитетные исходники: js/memchat/src, modules.json и extension/source-manifest.json. Карта/правила — AGENTS.md и docs/extension-architecture.md в source repository. Extension builder не требует готового generated userscript.

Из js/memchat, с установленными development dependencies:

```text
node dev/build-loader.cjs --check
npm run check:architecture
npm test
python extension/build.py --output <empty-owned-output>
python -m unittest discover -s tests/updater -p "test_*.py"
```

Python builder — standard library; Node/jsdom/Acorn/eslint-scope и Playwright нужны только разработчику. Packaged smokes запускаются по инструкции архитектуры против точного нового output в owned headless Chromium. Пользовательский браузер и бизнес-документы не используются для тестовых записей.

## Границы проверки

Packaged UI/transport/recovery tests используют настоящий Chromium и явно синтетические HTTP/credentials. Это не авторизованный production E2E и не проверка установленного у пользователя браузера. Нативная macOS-проверка на Windows не заявляется. Точные фактические результаты релиза — в его verification record.
